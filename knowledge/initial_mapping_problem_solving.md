Data Structuressegment_tree.py: Supports range queries (sum, min, max) and point/range updates in O(log n) time, ideal for interval problems.   fenwick_tree.py: Also known as a Binary Indexed Tree, it computes prefix sums and updates elements in O(log n), utilizing bitwise operations for a minimal memory footprint.   disjoint_set.py: Tracks elements partitioned into subsets, enabling near O(1) union and find operations using path compression and union by rank.   trie.py: A tree structure optimized for prefix-based string searching and autocomplete in O(L) time, where L is the string length.   sparse_table.py: Answers static range minimum/maximum queries in O(1) time after taking O(n log n) time to preprocess the data.monotonic_stack.py: Maintains a LIFO sorted sequence to efficiently find the "next greater" or "next smaller" element across an array in O(n) total time.   priority_queue.py: A heap implementation that fetches the minimum or maximum element in O(1), with insertions and deletions taking O(log n).   hash_map.py: Provides average O(1) time complexity for lookups and insertions, essential for state memoization and fast frequency tracking.   suffix_array.py: An array of all sorted suffixes of a given string, serving as a highly memory-efficient structure for complex substring searching and pattern matching.treap.py: A randomized balanced binary search tree that maintains heap properties, supporting O(log n) splits, merges, and order statistics queries.   Algorithmsbinary_search.py: Efficiently finds a target value or monotonic boundary within a sorted search space in O(log n) time.   depth_first_search.py: Traverses a graph deeply via recursion or a stack; the standard approach for finding connected components and cycle detection.breadth_first_search.py: Explores graph nodes level-by-level using a queue, guaranteeing the shortest path in unweighted networks.   dijkstra.py: Finds the shortest paths from a single source to all other nodes in a graph with non-negative edge weights in O((V+E) log V).kruskal.py: Computes the Minimum Spanning Tree (MST) of a graph by sorting edges and safely connecting them via a Disjoint Set in O(E log E).floyd_warshall.py: Uses dynamic programming to compute the shortest paths between all pairs of vertices in a dense graph in O(V^3) time.   kmp_search.py: Finds occurrences of a pattern in a text string in O(N + M) time by precomputing a longest prefix-suffix (LPS) array to avoid redundant comparisons.sieve_of_eratosthenes.py: Generates all prime numbers up to a maximum limit N efficiently in O(N log log N) time.topological_sort.py: Orders vertices in a Directed Acyclic Graph (DAG) linearly so that every directed edge u -> v strictly points forward.kadane.py: A dynamic programming technique used to find the maximum sum of a contiguous subarray within a 1-dimensional numeric array in O(n) time.
